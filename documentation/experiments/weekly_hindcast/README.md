# Weekly hindcast, 2025-26 season (peak-rectification arms)

Every peak-rectification config forecast from **every week** of the test window
(2025-10-04 .. 2026-05-30, 35 forecast dates), so any location and date can be inspected.
It is round 2's experiment at stride 1, seed 42 only, trained on round 2's pinned data cache
(sha256 `c91d9d81b8ab`). The round-2 3-seed run at stride 4 remains the source for the
seed-variance claims; this one is for inspection and the location and week breakdowns.

Generated by `scripts/experiments/export_hindcast_tables.py` from
`outputs/experiments/peak_rectification_weekly/`. Do not edit by hand; regenerate.

## Files

| file | what it is |
|---|---|
| `forecasts/<config>.csv` | one row per location x forecast date x horizon (7,420 rows per config) |
| `wis_by_location.md` | peak-phase WIS per location, as a change from baseline, biggest gains first |
| `wis_by_week.md` | WIS per forecast date across the season, as a change from baseline |
| `wis_by_location.csv`, `wis_by_week.csv` | the same, long format, every config, every phase |
| `summary.md` | the harness summary: pooled, peak and overall WIS by horizon |
| `manifest.json` | provenance: split, seeds, git SHA, data-cache hash, library versions |
| `examples/*.png` | sample inspection figures |

`forecasts/<config>.csv` columns:

| column | meaning |
|---|---|
| `cutoff_date` | last observed week the forecast was made from (the lab's `avl_date`) |
| `target_end_date` | week being forecast: `cutoff_date` + `horizon` weeks |
| `phase` | phase of the target week (`adiga_2026_10`: growth Nov 1-Dec 31, peak Jan 1-end Feb, decline Mar 1-Apr 15, plateau Apr 16-May 31, else off_season) |
| `observed` | weekly hospital admissions actually reported for the target week |
| `q05` .. `q95` | forecast quantiles; `q50` is the median |
| `wis` | weighted interval score of that row (lower is better) |

## Plotting

```bash
.venv/bin/python scripts/plot_forecasts.py --location Virginia --date 2026-01-10
.venv/bin/python scripts/plot_forecasts.py --location 06 --date 2025-12-13 --configs all --lookback-weeks 8
.venv/bin/python scripts/plot_forecasts.py --list-dates
```

One panel per config: observed series in black up to the forecast date, the median and the
50% and 90% intervals for 1-4 weeks ahead, and what was observed afterwards as hollow markers.
The function is `src.forecast_panels.plot_forecast_panels`.

## Caveats

- **90%, not 95%.** The model emits five quantiles (0.05, 0.25, 0.5, 0.75, 0.95), so the widest
  interval is 90%, and WIS is computed on those five rather than FluSight's 23. Deltas between
  configs are valid; absolute WIS is not comparable with FluSight-scored numbers.
- **US forecasts are not valid.** They are included in the files but excluded from every score.
  The model is trained on state rows (largest state value in training: 4,729, Texas), so it cannot
  reach the national level (about 21,000 in late December). The 1-week-ahead forecast collapses
  to the 30%-of-last-value floor, with all five quantiles equal. Do not read the US plots as
  model forecasts.
- **Scale.** WIS is in admissions, so pooled numbers are dominated by the large states
  (California, Texas, Florida, New York, Pennsylvania). Read `wis_by_location.md` for the
  per-location picture.
- **One seed.** Seed-to-seed spread was small in round 2 (peak WIS sd about 1.2) but not zero.
- **Forecast dates near the end** have targets in June (off_season); they are scored in overall
  WIS, as in the harness, but in no phase other than off_season.
